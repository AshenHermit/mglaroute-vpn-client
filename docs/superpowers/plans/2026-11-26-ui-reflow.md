# UI Reflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. No git repo at workspace root, but client has its own repo; commit steps are replaced by verification checkpoints where needed.

**Goal:** выровнять интерфейс клиента, убрать оверлапы/обрезания/белые скроллбары, добавить glass + параллакс, нейтральные цвета, страницу Settings и shadcn/animate-ui анимации.

**Architecture:** четыре зоны остаются, но center становится единственным скроллящимся контейнером; rail и connectionпанель компактные. Settings — обычная страница в center. UI-примитивы берём из shadcn registry и анимируем через `@animate-ui/cli` v2 (primitive-swap), не копируя папку `components/animate-ui` из Wired.

**Tech Stack:** Tauri 2, React 19, TS strict, Tailwind 4, shadcn CLI, `@animate-ui/react`, `motion`, Sonner, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-26-ui-redesign-shell-design.md` + одобренные в чате решения (чистый reflow, registry animate-ui, единая Settings-страница).

## Global Constraints

- All colors neutral: `oklch(L 0 0)`; accents only green `--primary` and red `--destructive`. No blue hue in tokens.
- Keep all `data-testid` hooks: `rail-zone`, `center-zone`, `right-zone`, `bottom-nav*`, `server-row`, `server-power`, `server-favorite`, `server-details`, `connection-status`, `active-server`, `connection-timer`.
- Don't vendor Wired's `src/components/animate-ui` folder. Use shadcn registry + `@animate-ui/cli`.
- No `next-intl`, no persisted secrets, no native-error text in notices.
- Tauri has no `window.scrollY`: parallax listens to pointer + `[data-testid=center-zone]` scroll.
- Timestamp format: local `Europe/Moscow`, `dd.MM.yyyy HH:mm:ss`.
- Window floor: `minWidth:360`, `minHeight:480`; default 900×640 unchanged.

## Review Focus

- Long remarks / numeric addresses in narrow center column → truncate + `title`, no per-word wraps. Test in Task 5.
- 360px window → icon-only rail, compact connection card, bottom nav not overlapping. Test in Task 4.
- 480px settings surface → form grid single-column via container queries. Test in Task 6.
- ISO timestamps with nanoseconds and Z → exact `26.11.2026 13:00:00`. Test in Task 5.
- Repeated notices / Sonner overlap → `noticeSeq` dedupe, bottom-right offset above bottom nav. Test in Task 2.
- Motion vs centering transforms → use CLI-managed primitive swap, no hand-written `-translate-*` on animated dialog. Verification in Task 2.
